# iOS Agent Memory (not tracked in git — local reference)

## Naming Convention
- SwiftLint disallows underscores in type names
- Use `IOS` prefix for iOS-specific types: `IOSAppState`, `IOSAppCoordinator`, `IOSRootView`
- Use `IPad` prefix for iPad-specific types: `IPadMainView`
- Use `IOS` prefix for sidebar: `IOSSidebarView`, `IOSSidebarRow`, `IOSSidebarDestination`
- File names match type names (e.g. `IOSAppState.swift`)

## Swift 6 Concurrency
- `@Observable` classes cannot be `Sendable` (mutable stored properties conflict)
- Use `@MainActor @Observable` instead for UI state classes
- Tests for `@MainActor` classes need `@MainActor` annotation on test methods

## Project Structure
- Source: `Sources/EmailerIOS/` (lib target), `Sources/EmailerIOSApp/` (executable)
- Tests: `Tests/EmailerIOSTests/`
- Views organized by function: `Views/Tabs/`, `Views/Sidebar/`, `Views/Placeholders.swift`
- Stores: `Stores/IOSAppState.swift`, `Stores/IOSAppCoordinator.swift`

## Build
- `swift build` works because Package.swift includes `.macOS(.v15)` alongside `.iOS(.v18)`
- iOS-only APIs guarded with `#if os(iOS)` (e.g. UIDevice.current.userInterfaceIdiom)
